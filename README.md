cninja-clone

A clone project inspired by Coding Ninjas, built as a frontend web application.

Features

Responsive user interface

Course-style landing page layout

Reusable React components

Modern styling with Tailwind CSS

Basic navigation structure


Tech Stack

React

JavaScript

HTML5

Tailwind CSS


Getting Started

Clone the repository

git clone https://github.com/softdev-nic/cninja-clone.git
cd cninja-clone

Install dependencies

npm install

Run the project

npm run dev 

The app will run locally at:

http://localhost:3000

Purpose

This project was built for learning and practice in frontend development and UI cloning.
